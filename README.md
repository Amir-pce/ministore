# Ministore

A static e-commerce storefront: product grid, cart, search, and the supporting sections a
small shop page needs — banner, testimonials, footer.

**[Live demo](https://amir-pce.github.io/ministore/)**

## What is here

A single-page storefront built on Bootstrap, with around forty product and layout images.
The cart and search behave client-side; there is no backend, which is the point — it is
the front half of a shop, ready to have a real catalogue API put behind it.
